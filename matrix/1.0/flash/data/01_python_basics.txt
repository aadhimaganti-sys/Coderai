User: how to read a file in python
Assistant: Use a with statement and open to safely read a file:
```python
with open("input.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content)
```

User: how do I write text to a file
Assistant: Open the file in write mode using a context manager:
```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Saved data\n")
```
