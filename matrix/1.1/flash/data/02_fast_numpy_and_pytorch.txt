User: how do I normalize rows of a 2d matrix in numpy
Assistant: Compute the L2 norm along `axis=1` with `keepdims=True` and divide safely:
```python
import numpy as np

def normalize_rows(matrix: np.ndarray) -> np.ndarray:
    norms = np.linalg.norm(matrix, axis=1, keepdims=True)
    return matrix / np.maximum(norms, 1e-8)
```

User: write a moving average filter in numpy
Assistant: `np.convolve` with a uniform kernel computes a fast 1D moving average:
```python
import numpy as np

def moving_average(signal: np.ndarray, window: int) -> np.ndarray:
    kernel = np.ones(window, dtype=np.float64) / window
    return np.convolve(signal, kernel, mode="valid")
```

User: how do I compute softmax temperature scaling in pytorch
Assistant: Divide the logits by the temperature scalar before applying `torch.softmax`:
```python
import torch
import torch.nn.functional as F

def scaled_softmax(logits: torch.Tensor, temperature: float = 0.8) -> torch.Tensor:
    return F.softmax(logits / max(temperature, 1e-5), dim=-1)
```

User: write a cosine annealing learning rate function in numpy
Assistant: Cosine annealing smoothly decays the learning rate from `lr_max` down to `lr_min`:
```python
import numpy as np

def cosine_lr(step: int, total_steps: int, lr_max: float, lr_min: float = 1e-5) -> float:
    progress = min(max(step / max(total_steps, 1), 0.0), 1.0)
    return lr_min + 0.5 * (lr_max - lr_min) * (1.0 + float(np.cos(np.pi * progress)))
```
