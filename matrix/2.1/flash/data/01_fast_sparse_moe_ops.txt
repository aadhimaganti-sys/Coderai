Assistant: Computing top-2 softmax routing weights and normalizing across selected experts dispatches tokens with minimal overhead:
```python
import torch
import torch.nn.functional as F

def top2_moe_route(x: torch.Tensor, router_weight: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
    logits = x @ router_weight.t()
    z_loss = (torch.logsumexp(logits, dim=-1) ** 2).mean() * 1e-3
    probs = F.softmax(logits, dim=-1)
    top_w, top_idx = torch.topk(probs, k=2, dim=-1)
    top_w = top_w / (top_w.sum(dim=-1, keepdim=True) + 1e-8)
    return top_w, top_idx, z_loss
```

User: implement a token-choice expert load balancer monitor in python
Assistant: Tracking token counts per expert computes the coefficient of variation so you can spot routing imbalance immediately:
```python
import numpy as np

def expert_balance_metrics(routed_indices: np.ndarray, num_experts: int = 4) -> dict:
    counts = np.bincount(routed_indices.ravel(), minlength=num_experts).astype(np.float64)
    fractions = counts / max(1.0, counts.sum())
    cv = float(np.std(fractions) / (np.mean(fractions) + 1e-9))
    return {"fractions": fractions.tolist(), "load_cv": round(cv, 4)}
```
